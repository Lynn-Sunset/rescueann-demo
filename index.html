THE MISSES THAT AVERAGES HIDE

A search can converge.
And still miss the point.

A good average recall can coexist with queries that miss most of their true neighbors. Spending more on every query is expensive. RescueANN asks which results need another look—and where to search next.

WHAT MAKES THE DIFFERENCE?

Choose the query.
Then choose the route.

The gate decides where to spend extra work. Alternate entries can make that work more useful when the first search settles in a poor region. Exact-work controls test that second effect.

SAME WORK FOR EVERY QUERY

Some gains survive.
Others narrow.

At exactly 10,240 DC per query, T2I severe failures fall from 41 to 33 out of 2,000. LAION, SPACEV, YFCC and DataComp differ from Stock by only 1–5 failures.

SAME WORK FOR EACH MATCHED QUERY

A useful route
still makes a difference.

On SciRepEval, Stock given B’s exact query-dependent budgets has 19 / 19 failures across two graph seeds. B has 11 / 10 on the same 4,000 queries.

Common continuation consumes exactly the prescribed work. On seven 10M graphs Stock uses ef950, B/S ef700. On SciRepEval’s arXiv graphs Stock uses ef1200, B/S ef950; the seeds share queries. The original simultaneous intervals resolve the T2I and SciRepEval seed42 reductions.

Borrowed K(q): matched per-query work

For seeds42 /777, both methods consume totals of 40,467,214 /40,049,471 DC, with p99 work 24,279 /23,803 DC. A prior B run supplies these budgets; its cost is excluded from Stock. Stock receives no B candidates or answers. This isolates search behavior after allocation, rather than providing a standalone allocator.

B and S: equal final answers under this control

B includes final widening; S omits it. Across 748,000 tested budget–query pairs, B and S return identical ordered IDs and distance bits under exact-work continuation. These are repeated budgets on previously used queries. There are 110 differing full trajectories, including five different computation multisets. This final-answer agreement does not establish general algorithm or trajectory equivalence. Natural-stopping behavior remains distinct.
